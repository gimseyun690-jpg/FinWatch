# FinWatch brand assets

- `finwatch-symbol.svg`: 투명 배경 심볼. 문서·발표 자료용
- `finwatch-app-icon.svg`: 네이비 배경 앱 아이콘 원본
- `finwatch-logo-light.svg`: 밝은 배경용 가로 로고
- `finwatch-logo-dark.svg`: 어두운 배경용 가로 로고
- `*.jpg`: SVG 원본에서 95% 품질로 출력한 전달용 이미지

SVG가 원본이다. 비율을 유지하고 심볼 내부 색상이나 요소 위치를 따로 변경하지 않는다. JPG는 투명도를 지원하지 않으므로 용도에 맞는 배경 버전을 사용한다.
