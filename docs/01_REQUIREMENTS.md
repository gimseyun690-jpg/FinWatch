# FinWatch 요구사항

## 1. 제품 정의

FinWatch는 개인 투자자가 가격, 뉴스, 기술적 지표, 포트폴리오와 가격 알림을 한곳에서 확인하고, 플랫폼 관리자가 생성형 AI 기능의 사용량과 비용 절감 효과를 관리할 수 있는 클라우드 기반 투자 정보 모니터링 PWA이다.

FinWatch는 증권 거래나 직접적인 투자 권유를 제공하지 않는다. 모든 기술적 신호와 AI 생성 결과는 투자 판단을 보조하는 참고 정보이다.

## 2. 사용자와 핵심 가치

### 개인 투자자

- 여러 서비스에 흩어진 관심종목, 뉴스, 기술적 분석 정보를 한 화면에서 확인한다.
- 긴 뉴스를 AI 핵심 요약으로 빠르게 이해한다.
- PC에서는 대시보드, 모바일에서는 설치 가능한 PWA로 이용한다.

### 플랫폼 관리자

- 기능별 AI 호출량과 토큰 사용량을 확인한다.
- 예상 비용, 캐시 적중률, 절감된 예상 비용을 확인한다.
- 비용이 큰 요청과 프롬프트 버전을 파악하여 운영을 개선한다.

## 3. MVP 필수 기능

### 사용자 기능

| ID | 기능 | 완료 조건 |
|---|---|---|
| U-01 | 기본 인증 | 데모 USER와 ADMIN을 구분하고 보호된 화면에 접근한다. |
| U-02 | 메인 대시보드 | 관심종목 가격·등락률, 포트폴리오 요약, 주요 뉴스와 알림 현황을 표시한다. |
| U-03 | 관심종목 | 관심종목을 조회·추가·삭제한다. |
| U-04 | 종목 상세 | 현재가, 등락률, 거래량, 가격 이력과 관련 뉴스를 표시한다. |
| U-05 | 기술적 분석 | 이동평균선, RSI, MACD 값과 매수·중립·매도 신호를 표시한다. |
| U-06 | 포트폴리오 | 보유 수량과 평균 매수가를 저장하고 평가금액·손익·수익률을 계산한다. |
| U-07 | 가격 알림 | 목표가 조건을 저장하고 조건 충족 상태를 표시한다. |
| U-08 | AI 뉴스 요약 | 선택한 뉴스의 핵심 요약, 키워드, 감성 및 생성 정보를 표시한다. |
| U-09 | PWA | 반응형 UI, 앱 설치 메타데이터, 새로고침 가능한 라우팅을 제공한다. |
| U-10 | AI 기술지표 해설 | 서버가 계산한 기술지표를 Gemini가 근거값과 충돌 신호 중심으로 설명하고 생성·캐시 정보를 표시한다. |
| U-11 | 일일 변화 브리핑 | 전일 대비 기술지표 변화와 신규 뉴스·공시의 일치·충돌·한계를 근거와 AI 감사 정보로 표시한다. |
| U-12 | 통합 종목 검색·탐색 | 국내·미국 종목을 회사명·심볼로 검색하고 선택한 종목의 상세 데이터와 모든 분석 기능을 일관되게 표시한다. |
| U-13 | 환율·기준통화 평가 | USD/KRW 환율의 출처·기준시각을 표시하고 원통화 값을 보존하면서 혼합 포트폴리오의 현재 평가액을 KRW로 환산한다. |

### AI 운영 최적화 기능

| ID | 기능 | 완료 조건 |
|---|---|---|
| A-01 | 입력 전처리 | HTML, 광고 문구와 중복 문장을 제거하고 입력 길이를 제한한다. |
| A-02 | 결과 캐시 | 뉴스 ID와 프롬프트 버전 기반 키로 Redis 캐시를 조회·저장한다. |
| A-03 | 사용량 기록 | 캐시 여부와 관계없이 요청 로그를 남긴다. 신규 호출은 입·출력 토큰과 비용을 기록한다. |
| A-04 | 프롬프트 버전 | 요약 결과와 캐시 키에 사용한 프롬프트 버전을 포함한다. |
| A-05 | 관리자 지표 | 호출 수, 토큰, 예상 비용, 캐시 적중률, 절감 비용, 기능별 사용량을 표시한다. |
| A-06 | 비용 요청 목록 | 비용이 큰 AI 요청을 내림차순으로 조회한다. |

## 4. 핵심 업무 규칙

1. 캐시 키는 최소 `기능 + 대상 식별자 + 입력 스냅샷 + 계산·프롬프트 버전`을 포함한다.
2. 동일 뉴스와 동일 프롬프트 버전의 유효한 캐시가 있으면 AI 모델을 호출하지 않는다.
3. 캐시 적중 요청도 운영 요청 수와 응답시간 통계에는 포함한다.
4. 예상 비용은 모델별 입력·출력 단가 설정과 실제 토큰 수로 계산한다.
5. 캐시 절감 비용은 해당 결과를 새로 생성했을 때 들었을 것으로 추정되는 비용이다.
6. 기술적 지표는 가격 이력에서 서버가 계산하며 계산 기간과 기준 시각을 응답에 포함한다.
7. 포트폴리오 평가 결과는 저장 값이 아니라 최신 가격을 이용해 조회 시 계산한다.
8. 가격과 뉴스의 출처 및 기준 시각을 사용자 화면에 표시한다.
9. Gemini는 기술지표를 계산하거나 수정하지 않고 서버가 계산한 구조화 스냅샷의 의미만 설명한다.
10. AI 기술지표 해설은 목표주가·수익률 예측·직접 매수/매도 명령을 제공하지 않으며 모든 핵심 설명을 서버가 부여한 근거 ID와 연결한다.
11. 일일 변화 브리핑은 기술·뉴스·공시 관점을 하나의 매수·매도 점수로 합치지 않고 각 관점과 충돌 근거를 분리한다.
12. 종목 검색은 로컬 마스터를 사용하고 시세·일봉·뉴스는 선택·관심·보유 종목만 온디맨드 수집하며 모든 기능은 동일한 `(market, symbol)`을 사용한다.
13. 환율 없이 다른 통화를 합산하지 않으며 매수 당시 환율이 없으면 원화 매입원가·손익·환차손익을 생성하지 않는다.

## 5. 화면 요구사항

작품소개서 목업의 다크 대시보드와 시안·초록 포인트를 기본 시각 방향으로 사용한다.

- Desktop: 메인 대시보드, 종목 상세/기술 분석, AI 뉴스 요약, 관리자 AI 비용 대시보드
- Mobile: 홈, 관심종목, 뉴스, 알림, 내정보 하단 내비게이션
- 공통 상태: 로딩, 빈 결과, API 오류, 데이터 갱신 시각, 캐시 적중 여부
- 접근성: 색상만으로 상승·하락과 신호를 구분하지 않고 텍스트 또는 아이콘을 병기한다.

## 6. 비기능 요구사항

- 보안: 비밀번호 해시 저장, 역할 기반 관리자 접근, 비밀정보 환경변수 관리
- 성능: 캐시 적중 AI 요약은 외부 모델 호출 없이 반환
- 안정성: 외부 주가·뉴스·AI API 실패 시 명확한 오류와 재시도 가능 상태 제공
- 관측성: 요청 ID, 응답시간, 외부 API 오류를 구조화 로그로 기록
- 테스트: 핵심 서비스 단위 테스트와 첫 번째 Vertical Slice 통합 테스트 제공
- 데이터: 모든 금액은 통화 코드를 포함하고 날짜·시간은 서버에서 UTC 저장

## 7. MVP 제외 및 향후 기능

다음 기능은 작품소개서의 향후 계획 또는 범위 밖 기능이므로 핵심 흐름 완성 전 구현하지 않는다.

- 실제 매매, 증권 계좌 연동, 투자금 이체
- 자체 주가 예측 모델 학습
- 커뮤니티와 소셜 기능
- 복잡한 MSA, Kubernetes, EKS
- 모델 자동 라우팅과 일일 예산 기반 절약 모드
- 모바일 푸시 알림, 자동 PDF 리포트
- 사용자별 관심 산업 분석과 고급 지지선·저항선
- AI 모델별 비용 비교

## 8. MVP 합격 시나리오

1. 사용자가 회사명 또는 심볼로 국내·미국 종목을 검색하고 결과에서 SK하이닉스를 선택한다.
2. 종목 상세에서 가격 차트, 이동평균선, RSI, MACD와 관련 뉴스를 확인한다.
3. AI 기술지표 해설을 요청해 근거값·충돌 신호와 `cacheHit=false` 결과를 확인한다.
4. 같은 종목·일봉 스냅샷의 해설을 다시 요청해 `cacheHit=true`를 확인한다.
5. 뉴스 하나를 선택해 AI 요약의 MISS/HIT를 확인한다.
6. 관리자로 전환해 뉴스와 기술지표 해설의 호출 수, 토큰, 비용, 캐시 적중률과 절감 비용 증가를 확인한다.
